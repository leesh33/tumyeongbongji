# fonts/ — 페이퍼로지(Paperlogy)

속보이네 화면과 카드 PNG가 쓰는 글꼴입니다. 외부 CDN 없이 저장소에서 직접 서빙합니다
(오프라인·CDN 장애에도 같은 화면이 나오고, PNG 내보내기가 같은 파일을 그대로 심습니다).

| 파일 | 굵기 | 쓰는 곳 |
| --- | --- | --- |
| `Paperlogy-4Regular.woff2` | 400 | 본문 |
| `Paperlogy-5Medium.woff2` | 500 | 카드 원재료 줄 |
| `Paperlogy-6SemiBold.woff2` | 600 | 카드 라벨, 작은 제목 |
| `Paperlogy-7Bold.woff2` | 700 | 제목, 수치 |
| `Paperlogy-8ExtraBold.woff2` | 800 | 강조(제품 이름, 버튼) |

각 파일은 한글 11,172자(완성형 전부)와 숫자·영문·문장부호를 포함합니다(11,723자,
`tools/check_glyphs.py`로 확인).

- 배포처: https://noonnu.cc (페이퍼로지) · 원 배포 PT& (www.designptn.com)
- 받은 곳: jsDelivr `https://cdn.jsdelivr.net/gh/fonts-archive/Paperlogy/Paperlogy-4Regular.woff2`
  (같은 파일이 `projectnoonnu/2408-3`에도 있습니다)
- 라이선스: SIL Open Font License 1.1 (상업적 사용·임베딩·재배포 허용, 글꼴 단독 판매 금지).
  전문은 같은 폴더의 `OFL.txt`에 있습니다. 파일을 수정해 굵기를 바꾸지 않았으므로
  예약 글꼴 이름(Paperlogy)을 그대로 씁니다.
